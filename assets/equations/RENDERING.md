# Equation assets

Generated from the accompanying formulas.json with MathJax 3.2.2 (Apache-2.0), TeX base/AMS and SVG output with local glyph paths. Equation labels are outside SVG math. No browser MathJax layout or remote font is needed. Light/dark variants use GitHub theme-context fragments. Source: https://registry.npmjs.org/mathjax-full/3.2.2 . The MathJax license is preserved alongside these generated assets.
