# Historical material

The [current paper](../paper/main.pdf) is the recommended starting point.
This directory preserves earlier drafts, export metadata and workspace
records for traceability; they are not competing current entry points.

- [Original C021 note](c021-original/C021_REVIEW_NOTE.md): the earlier
  complete-base, **separated-reflection** result, with its SVG equations.
- [Original review packet](c021-original/C021_review_packet.zip): earlier
  code, inputs and source records; scope differs from the expanded paper.
- [Earlier standalone proofs](workspace/proofs/c021_uniform_local_limit.md):
  development material preceding the integrated paper; neighbouring files
  cover the foundation, all-height reflection and deletions.
- [Historical finite-suite guide](workspace/tests/C021_EXTENSIONS_TESTS.md):
  exact bounds and original workspace commands.
- [Earlier export provenance](workspace/PUBLIC_EXPORT.json) and
  [typesetting record](workspace/BUILD_PROVENANCE.json).

Files here retain their original public bytes, including old path references,
workspace-specific instructions and dated presentation statements. Some
relative links therefore refer to the original layout. Use the
[relocation map](../evidence/RELOCATION.json) and current reproduction guide
for working paths and commands. Old checksum files are historical records;
use the root [SHA256SUMS.txt](../SHA256SUMS.txt) for this distribution.
