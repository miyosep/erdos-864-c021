# Current paper

**[Read main.pdf](main.pdf)** · [Edit main.tex](main.tex) · [Read main.md](main.md)

Sage Kim, Peking University. External-review draft, 5 November 2026.
These are three formats of the same current paper.

Theorem 1 is the uniform integer representation estimate. Corollary 1.1
contains the deletion and all-height reflected-span applications. Six
supporting lemmas supply the parametrization, exceptional count, CRT/Fourier
estimate, uniform slab argument, deletion loss and exact hull calculation.

To build, run `tectonic --untrusted main.tex` here. The bibliography is
embedded; there are no supporting image or bibliography files. See
[REPRODUCING.md](../REPRODUCING.md) for requirements and finite checks.

[Review materials](../review/README.md) describe the proof checkpoints,
finite checks and verification limitations.
